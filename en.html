00 · CONTEXT

What problem does the paper define?

ReFocus adds the interaction that one-shot episodic-memory retrieval leaves out: users can see a wrong result and refine the search.

01

EM-NLQ is one-shot

Given a long first-person video and a natural-language question, a conventional EM-NLQ system predicts one temporal window. It assumes that the question is complete and the first prediction is useful.

In practice, users often remember only partial details or discover the missing detail after seeing a wrong clip.

02

EM-QnF makes correction part of the task

The user asks a question, sees an initial prediction, and provides feedback. Feedback may add information, exclude a distractor, or indicate whether to search before or after the current span.

The process can continue for multiple turns.

03

ReFocus is a lightweight adaptation

FALM reads the video, query, reference span, and feedback, predicts a per-clip alignment score, and injects that signal into an existing EM-NLQ model through a lightweight EM Adapter.

The base model does not need to be rebuilt from scratch.

02A · ANNOTATION DETAILS

The relationship inside one sample

A query can be paired with multiple reference spans and multiple feedback expressions.

One interaction record

Original query Q→Prediction Rf→Feedback F→Target span Rq

The model is trained to recover the target from different error types, rather than memorize one correction sentence.

Three information types

  • Additional: object, color, person, action, or scene.
  • Contrastive: how the wrong and target spans differ.
  • Temporal: search before or after the reference.

02C · FEEDBACK RECIPE

How is feedback generated?

The feedback is constructed around why a prediction is wrong and how a user might redirect the search.

STEP 1

Sample reference span

Take the correct response span as the target Rq.

STEP 2

Generate captions

Describe the target and reference clips with an LVLM.

STEP 3

Explain the difference

Describe how the initial prediction differs from the target.

STEP 4

Construct feedback

Use an LLM to produce additional, contrastive, and temporal cues.

Why synthetic feedback?Long videos and multi-turn annotation are expensive to label manually. The authors scale the data with synthetic feedback and evaluate transfer to human-written feedback.

Why R@1, R@3, and R@5?

R@1 checks the first candidate. R@5 checks whether any of the first five candidates hits the target, so the two metrics reflect the top choice and candidate coverage.

Why IoU 0.3 and 0.5?

IoU 0.3 is more tolerant of temporal boundary differences. IoU 0.5 is stricter and requires greater overlap with the target span.

What would a real board require?

A hidden test set, a fixed evaluator, submission limits, and separate query-only and query-plus-feedback reporting.

05 · MODEL

What does FALM do inside the model?

FALM converts feedback into clip-level alignment weights that can be used by an existing temporal-grounding model.

Video encoderVisual feature for each clip
+
Query encoderOriginal question semantics
+
Feedback encoderCorrections and extra cues
→
Alignment score PFeedback match for each clip

Transformer encoder-decoder: fuses video, query, and feedback to predict per-clip alignment.

EM Adapter: two learned scalars inject FALM scores into an existing EM-NLQ model.

Multi-turn: per-feedback outputs are combined with late fusion.

06 · PIPELINE

From source video to feedback alignment.

The data-generation path turns existing NLQ datasets into EM-QnF; the inference path uses FALM to reweight video clips.

01

Source data

Ego4D-NLQ, GoalStep, and HD-EPIC provide videos, queries, and target spans.

video + query + target span
02

Feedback construction

Sample reference spans, generate captions, and produce additional, contrastive, and temporal feedback.

query + wrong prediction + feedback
03

FALM alignment

Encode video, query, and feedback; predict alignment scores and reweight the base model features.

clip score P → EM Adapter
04

Temporal evaluation

Predict a new time span and evaluate it with Recall@K and temporal IoU.

prediction → R@K / IoU

Finding 1: feedback is not automatically used

Continuing to train GroundNLQ and OSGNet on EM-QnF alone produces small gains. FALM explicitly converts feedback into clip alignment.

Finding 2: ReFocus produces larger gains

Across the main settings, ReFocus(GroundNLQ) reaches gains of up to about +4.9 R@1 and +5.4 R@5, depending on dataset and IoU threshold.

Finding 3: cross-dataset behavior matters

When trained on Ego4D-QnF and evaluated on GoalStep-QnF and HD-EPIC-QnF, ReFocus still improves over the corresponding baseline.

07A · ABLATIONS

What contributes to the gains?

These experiments test whether the model actually uses the different feedback signals.

TEMPORAL

Temporal cues help most

Whether to search before or after the reference directly narrows the search space.

CONTAINS

Contains finds the right content

Object attributes, actions, and scene details identify clips that match the intended event.

NOT-CONTAINS

Not-contains avoids distractors

Excluded content can lower the score of visually similar but incorrect clips.

ADAPTER

The adapter matters

Removing the EM Adapter reduces performance, showing that FALM scores need model-specific scaling and shifting.

Upper bound:Using ground-truth FALM labels reaches 40.93 R@1@IoU0.3 on an Ego4D subset, compared with 33.13 using predicted labels.

07D · LIMITATIONS

What are the current limitations?

These limitations define the current scope of the method.

01

LLM-generated hallucinations

Some generated feedback may include details that are not in the video, adding noise to training.

02

Caption-based feedback

Feedback is generated from language descriptions of spans rather than full video context, which may lose fine visual details.

03

Multi-turn modeling is basic

The proposed extension processes feedback independently and fuses the outputs; it does not track an evolving conversational state.

04

The evaluation is temporal grounding

Recall and IoU measure span localization. They do not by themselves establish reliable natural-language explanations.
