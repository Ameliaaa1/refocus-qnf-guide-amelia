01 · VIDEO

视频是什么样？

模型面对的是来自可穿戴摄像头的第一视角、连续生活记录。用户不是问“这段视频是什么类别”，而是要找出一个事件在长视频中的确切时间窗口。

02 · ANNOTATION

标注不是一句答案，而是一轮纠错记录。

每一条反馈都指向模型之前的一次错误预测，让“用户如何把模型拉回正确片段”变成可训练、可复现的数据。

sample.jsonl
{
  "query": "我在客厅和谁说话？",
  "feedback": "那个人正在弹吉他，不只是走过。",
  "pred_timestamp": [434.25, 443.97],
  "timestamps": [109.08, 125.61],
  "duration": 480.0
}
A

内容补充

“不是白色杯子，是蓝色大杯子。”

B

排除干扰

“不是电视旁边，是植物附近。”

C

时间提示

“请看前面，发生在挂旗出现之前。”

03 · BENCHMARK

三套来源数据，一个新的交互任务。

EM-QnF 建立在已有 episodic memory benchmark 之上，把一次性 NLQ 扩展成可以多轮纠正的检索。

05 · PIPELINE

从原始视频到反馈对齐。

数据生成和模型推理是两条相互衔接的链路：先把已有 NLQ 变成 EM-QnF，再用 FALM 把反馈转成片段级权重。

01

原始数据

Ego4D-NLQ / GoalStep / HD-EPIC 提供视频、问题和真实时间段。

video + query + ground truth span
02

构造反馈

采样参考片段，用 LVLM 生成描述，再由 LLM 生成内容、排除和时间反馈。

query + wrong prediction + feedback
03

FALM 对齐

编码视频、问题和反馈，计算每个 clip 的 alignment score，重加权原模型特征。

clip score P → EM Adapter
04

评测反馈后的定位

输出新的时间段，用 Recall@K 和 IoU 衡量是否找回正确事件。

prediction → R@K / IoU
